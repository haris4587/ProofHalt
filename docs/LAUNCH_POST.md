# ProofHalt launch post

ProofHalt is live: evidence-bound emergency governance for autonomous protocols, built on GenLayer.

Instead of asking an LLM whether a protocol should halt, ProofHalt binds a versioned security constitution, hash-pinned evidence, independent validator retrieval, deterministic safety gates and an append-only verdict history. The browser now performs real Studionet writes and displays wallet confirmation, submission, consensus acceptance, finality, execution receipts and readback.

The public Studionet case is intentionally honest: validators finalized every write, but refused HALT authorization when their execution environment could not retrieve the submitted web evidence. That fail-closed result is the point—unavailable evidence cannot become emergency authority.
